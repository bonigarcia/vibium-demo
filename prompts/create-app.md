# Prompt used to create the app

The starting app (the `start` tag) was generated by a coding agent from the prompt below. The ticket for the demo (the EARLYBIRD banner) is in the [README](../README.md#the-demo).

One requirement is deliberate: the Register button is the last element on the page. A fixed banner added later at the bottom of the screen can then cover it, which is what the agent finds in Part 1 of the demo.

## Prompt

```text
Build a small web app: the registration page for a fictional event called "Acme Testing Conference 2026".

Technical requirements:
- Plain HTML, CSS and JavaScript, no framework. Vite as the dev server and Vitest for unit tests.
- npm scripts: "npm run dev" starts the app and "npm test" runs the tests.
- Keep the logic separate from the UI: pure functions in src/registration.js, DOM handling in src/main.js.
- Short, readable code: it will be shown on screen during a conference talk.
- A short README.md explaining how to start the app and run the tests.

The page:
- At the top, a section with the event information: date, venue, and a program with six fictional talks. Use invented speaker names.
- Below it, the registration form with: name, email, ticket type (General, €120; Student, €60), an optional promo code, and a required checkbox to accept the privacy policy.
- Every field has an associated <label>.
- The "Register" button is the last element on the page, with no footer or content below it.
- On submit with valid data, show "Registration confirmed" with the name and the final price. With invalid data, show an error message next to each affected field.
- Promo codes: for now only FRIENDS10 exists (10% off). An unknown code is rejected with a message.

Unit tests with Vitest for data validation and price calculation, including promo codes.

When you are done, install the dependencies, run the tests and check that they pass. Do not add anything that was not requested.
```
